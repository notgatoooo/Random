1. Getting Key URL

To get the Key URL, you need to first execute Overdrive H. Once you do that, you need to click the GET button on the left side of the UI.

2. Doing The Key

Once you get the Key URL on Overdrive H UI, you'll want to go into a browser (you're probably in one right now) and paste that link in there. You should see something like this page:

Once you see this page, click the Add Credits button/text.

3. Doing The Linkvertise

Once you have successfully clicked the button, you should go to the URL: https://linkvertise.com/...; if not, go back to the key system page and click again. Once you get to that page, click the Get Link button.

Once done, select the Watch Ads option. Once done, click Continue. Now you should see something like the image below. If yes, just click Skip Ad button.

Until you get to this page where you will want to click the Open button, which should automatically redirect you back to the key system, and you've got your First credit!

4. Rest To-Do

You will have to repeat this step if you want to get more key time. The minimum is 2 credits for 6 hours of key system; the maximum is 21 credits for 14 days of key system.
