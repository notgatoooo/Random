Overdrive H Addons

[1] Syntax

Overdrive H Addons syntax is straightforward: odh_shared_plugins.CreateTab("Name", "icon") creates your own tab, tab:AddSection("Name", "Subtitle") creates a section container inside it, and instance methods are invoked on that section via section:AddInstance(...). Here is a basic example:

LUAU 
local shared = odh_shared_plugins

local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddToggle("My Toggle", function(state)
    if state then
    else
    end
end)

[2] Instances

Every UI component created under your section is called an Instance. Below are all the instances and utilities available in Overdrive H, along with their parameters, their return values, and the methods they expose.

Tab

CreateTab creates your own top-level tab that holds every section of your addon (name: string, icon: string) → table. The icon file name must always end with .png.

LUAU 
local shared = odh_shared_plugins

local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")

Section

AddSection is called on a tab and creates a new category container, with its own custom subtitle, for holding all your addon's instances (name: string, subtitle: string) → table.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")

local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

Label / TextLabel

Label (or TextLabel) creates static display text for credits, titles, or general information (text: string, allow_edit: boolean) → table | void. When allow_edit is passed, it returns a table exposing :SetValue(text), which replaces the label text with the provided string.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddLabel("Credits: @my_name")

local label = my_own_section:AddLabel("Credits: @my_name", true)
label:SetValue("Credits: @another_name")

Paragraph

Paragraph displays a multi-line formatted text block with a title and description (title: string, description: string, allow_edit: boolean) → table | void. When allow_edit is passed, it returns a table exposing :SetValue(text), which replaces the description text with the provided string.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddParagraph("title", "description")

local paragraph = my_own_section:AddParagraph("title", "description", true)
paragraph:SetValue("a brand new description")

Toggle

Toggle switches between active and inactive states, passing a boolean state to its callback (feature_name: string, callback: closure) → closure. Calling the returned closure flips the toggle state and fires the callback with the new boolean.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

local toggle = my_own_section:AddToggle("toggle", function(state)
    if state then
        print("Toggled On")
    else
        print("Toggled Off")
    end
end)

toggle()

Slider

Slider provides an adjustable number bar with minimum, maximum, and default values (feature_name: string, minimum: int | float, maximum: int | float, default: int | float, callback: closure) → table. It returns a table exposing :SetValue(num), which changes the slider value and fires the callback with the new number.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

local slider = my_own_section:AddSlider("slider", 10, 30, 20, function(int_or_float)
    shared.Notify("the computer process is at " .. int_or_float .. "%", 3)
end)

slider:SetValue(25)

Colorpicker

Colorpicker allows picking a custom color, passing a Color3 value to the callback (feature_name: string, default_color: Color3, callback: closure) → table. It returns a table exposing :SetHexValue(hex) and :SetRGBValue(color), which change the picked color and update every other property.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

local colorpicker = my_own_section:AddColorpicker("colorpicker", Color3.fromRGB(255, 255, 255), function(color3rgb)
    print(color3rgb)
end)

colorpicker:SetHexValue("#FF0000")
colorpicker:SetRGBValue(Color3.fromRGB(0, 255, 0))

Dropdown

Dropdown lets the user choose an entry from an array (feature_name: string, default_list: array, callback: closure) → table. It returns a table exposing :Select(text), which selects an existing item from the current lists, and :ChangeItems(list), which replaces the old items with the provided array items.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

local dropdown = my_own_section:AddDropdown("dropdown", {"list #1", "list #2"}, function(selected)
    shared.Notify(selected, 2)
end)

dropdown:Select("list #2")
dropdown:ChangeItems({"changed 1", "changed 2"})

PlayerDropdown

PlayerDropdown creates an automatic player selection dropdown, passing the selected Player instance to the callback (feature_name: string, callback: closure) → void.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddPlayerDropdown("select player", function(player)
    shared.Notify(player.Name .. " has been selected.", 2)
end)

TextBox

TextBox provides a text input field that passes the submitted text to its callback (feature_name: string, callback: closure) → void.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddTextBox("textbox", function(text)
    shared.Notify(text)
end)

Button

Button triggers a direct callback function on click (feature_name: string, callback: closure) → void.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddButton("button", function()
    shared.Notify("this is a button", 2)
end)

Keybind

Keybind registers a key that fires an action whenever pressed (feature_name: string, default_key: string, callback: closure) → void.

LUAU 
local shared = odh_shared_plugins
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

my_own_section:AddKeybind("keybind", "U", function()
    shared.Notify("Keybind test", 1)
end)

Notifications

Notify pops up an Overdrive H notification banner with a message and an optional type (text: string, type?: integer) → void. Types: 0 = Warning, 1 = Error, 2 = Success, 3 = Information.

LUAU 
local shared = odh_shared_plugins

shared.Notify("Addon loaded successfully!", 2)

Identifiers & User Metadata

Identifiers provide user tier booleans and environment metadata strings. is_premium_user, is_exclusive_user, and is_serverbooster_user return boolean (true / false); all other fields return string.

LUAU 
local shared = odh_shared_plugins

print("Premium:", shared.is_premium_user)
print("Exclusive:", shared.is_exclusive_user)
print("ServerBooster:", shared.is_serverbooster_user)
print("Discord Name:", shared.discord_name)
print("Discord ID:", shared.discord_id)
print("Executor:", shared.executor)
print("HWID:", shared.hwid)
