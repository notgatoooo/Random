Overdrive H Addons

[1] Syntax

Overdrive H Addons syntax is straightforward: odh_shared_plugins.AddSection("Name") creates a section container, and instance methods are invoked on that section via section:AddInstance(...). Here is a basic example:

LUAU 
local shared = odh_shared_plugins

local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddToggle("My Toggle", function(bool)
    if bool then
    else
    end
end)

[2] Instances

Every UI component created under your section is called an Instance. Below are all the instances and utilities available in Overdrive H, along with their parameters and how to call them.

Section

Section creates a new category container for holding all your addon's instances (arg1: string).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

Label / TextLabel

Label (or TextLabel) creates static display text for credits, titles, or general information (arg1: string).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddLabel("Credits: @my_name")

Paragraph

Paragraph displays a multi-line formatted text block with a title and description (arg1: string, arg2: string).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddParagraph("Important Notice", "Here is a detailed description of the addon features.")

Toggle

Toggle switches between active and inactive states, passing a boolean bool to its callback (arg1: string, arg2: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddToggle("toggle", function(bool)
    if bool then
        print("Toggled On")
    else
        print("Toggled Off")
    end
end)

Slider

Slider provides an adjustable number bar with minimum, maximum, and default integers (arg1: string, arg2: integer, arg3: integer, arg4: integer, arg5: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddSlider("slider", 10, 30, 20, function(int)
    shared.Notify("the computer process is at " .. int .. "%", 3)
end)

Dropdown

Dropdown lets the user choose an entry from a table. Returns an instance reference with .Select() and .Change() methods (arg1: string, arg2: table, arg3: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

local dropdown = my_own_section:AddDropdown("dropdown", {"list #1", "list #2"}, function(selected)
    shared.Notify(selected, 2)
end)

dropdown.Select("list #2")
dropdown.Change({"changed 1", "changed 2"})

PlayerDropdown

PlayerDropdown creates an automatic player selection dropdown passing the selected Player instance to the callback (arg1: string, arg2: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddPlayerDropdown("make gay", function(player)
    shared.Notify(player.Name .. " is now a gay person.", 1)
end)

TextBox

TextBox provides a text input field that passes submitted text to its callback (arg1: string, arg2: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddTextBox("textbox", function(text)
    shared.Notify(text)
end)

Button

Button triggers a direct callback function on click (arg1: string, arg2: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddButton("button", function()
    shared.Notify("this is a button", 2)
end)

Keybind

Keybind registers a key that fires an action whenever pressed (arg1: string, arg2: string, arg3: function).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddKeybind("keybind", "U", function()
    shared.Notify("Keybind test", 1)
end)

Colorpicker

Colorpicker allows picking a custom color, passing a Color3 value to the callback (name: string, default_color: Color3, callback: closure).

LUAU 
local shared = odh_shared_plugins
local my_own_section = shared.AddSection("Example Addon")

my_own_section:AddColorpicker("ESP Color", Color3.fromRGB(255, 0, 0), function(color)
end)

Create Hidden Instance

create_hidden_instance creates an instance completely hidden in non-odh contexts without any trace (arg1: string, arg2: Instance).

LUAU 
local shared = odh_shared_plugins

local part = shared.create_hidden_instance("Part", workspace)

Notifications

Notify pops up an Overdrive H notification banner with a message and an optional type (text: string, type?: integer). Types: 0 = Warning, 1 = Error, 2 = Success, 3 = Information.

LUAU 
local shared = odh_shared_plugins

shared.Notify("Addon loaded successfully!", 2)

Kick

kick invokes the built-in Overdrive H custom player disconnection with an optional reason (reason?: string).

LUAU 
local shared = odh_shared_plugins

shared.kick("reason")

Identifiers & User Metadata

Identifiers provide user tier booleans and environment metadata strings. is_premium_user, is_exclusive_user, and is_serverbooster_user return boolean (true / false); all other fields return string.

LUAU 
local shared = odh_shared_plugins

print("Premium:", shared.is_premium_user)
print("Exclusive:", shared.is_exclusive_user)
print("ServerBooster:", shared.is_serverbooster_user)
print("Discord Name:", shared.discord_name)
print("Discord ID:", shared.discord_id)
print("Executor:", shared.executor)
print("HWID:", shared.hwid)
