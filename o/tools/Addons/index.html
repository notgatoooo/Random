Overdrive H Addons

[1] Syntax & Architecture

Every addon runs inside the Overdrive H environment and interacts directly with the global table odh_shared_plugins. The UI hierarchy strictly follows a three-tier tree:

The Three-Tier Rule for Humans and AI Agents

1. Tab is the top-level navigation container created via shared.CreateTab(...).
2. Section is a group container created strictly on a tab instance via tab:AddSection(...).
3. Instances (buttons, toggles, sliders, etc.) can only be attached to a section instance via section:Add...(...).

LUAU 
--> Overdrive H On Top.

local shared = odh_shared_plugins

-- Step 1: Create your Tab
local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")

-- Step 2: Create a Section inside your Tab
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

-- Step 3: Attach interactive UI instances to your Section
my_own_section:AddToggle("My Toggle", function(state)
    if state then
        print("Toggled On")
    else
        print("Toggled Off")
    end
end)

[2] Instances & API Reference

Below is the exhaustive specification of every available method, constructor, parameter type, return value, and mutating method exposed in Overdrive H.

CreateTab

shared.CreateTab(<string> name, <string> icon): <table>

Creates the top-level tab container that holds your sections.

Icon String Formatting Rule (Do Not Skip)

1. Upload your icon as a .png image to a GitHub repository.
2. Take the raw GitHub URL, e.g.: https://raw.githubusercontent.com/axioriasolver/testplugin/refs/heads/main/icon.png
3. Strip https://raw.githubusercontent.com from the front and strip .png from the end.
4. The result must be: "/axioriasolver/testplugin/refs/heads/main/icon"

LUAU 
local shared = odh_shared_plugins

local my_own_tab = shared.CreateTab("My Plugin", "/axioriasolver/testplugin/refs/heads/main/icon")

AddSection

tab:AddSection(<string> name, <string> subtitle): <table>

Called directly on a tab object to create a titled category container with a customizable subtitle banner. All UI elements (labels, buttons, toggles, sliders, etc.) are parented to this section table.

LUAU 
local my_own_section = my_own_tab:AddSection("Example Addon", "CUSTOM SUBTITLE")

Label / AddLabel

section:AddLabel(<string> text, <bool> allow_edit): allow_edit ? <table> : <void>

Creates a single-line static or dynamic text label. If allow_edit is true, it returns a controller table with mutating methods. If omitted or false, it returns nil.

  • :SetValue(<string> text): <void> — Modifies the displayed label text to the newly provided string.
LUAU 
-- Static label (cannot be updated programmatically)
my_own_section:AddLabel("Credits: @my_name")

-- Editable label (returns controller with :SetValue)
local label = my_own_section:AddLabel("Credits: @my_name", true)
label:SetValue("Credits: @another_name")

Paragraph / AddParagraph

section:AddParagraph(<string> title, <string> description, <bool> allow_edit): allow_edit ? <table> : <void>

Creates a multi-line formatted content box with an authoritative title and descriptive text body. If allow_edit is true, it returns a controller table.

  • :SetValue(<string> text): <void> — Modifies the description body text to the newly provided string.
LUAU 
-- Static paragraph
my_own_section:AddParagraph("title", "description")

-- Editable paragraph (returns controller with :SetValue)
local paragraph = my_own_section:AddParagraph("title", "description", true)
paragraph:SetValue("a brand new description")

Toggle / AddToggle

section:AddToggle(<string> feature_name, <closure> callback): <closure>

Creates a binary on/off switch. Invokes callback(state: boolean) whenever clicked by the user. Crucial: It returns a closure function. Calling this returned closure programmatically toggles the state and fires the callback.

  • (): <void> — Inverts the toggle state and invokes the registered callback with the updated boolean state.
LUAU 
local toggle = my_own_section:AddToggle("toggle", function(state)
    if state then
        print("Toggled On")
    else
        print("Toggled Off")
    end
end)

-- Flip state programmatically:
toggle()

Slider / AddSlider

section:AddSlider(<string> feature_name, <int|float> minimum, <int|float> maximum, <int|float> default, <closure> callback): <table>

Creates an interactive draggable numeric slider bounded between minimum and maximum values. Fires callback(value: number) when changed.

  • :SetValue(<int|float> num): <void> — Programmatically sets the slider value, moves the thumb, and invokes the callback with the new number.
LUAU 
local slider = my_own_section:AddSlider("slider", 10, 30, 20, function(int_or_float)
    shared.Notify("the computer process is at " .. int_or_float .. "%", 3)
end)

-- Set value programmatically:
slider:SetValue(25)

Colorpicker / AddColorpicker

section:AddColorpicker(<string> feature_name, <color3> default_color, <closure> callback): <table>

Renders an RGB color picker dialog. Fires callback(color: Color3) whenever a color is selected.

  • :SetHexValue(<string> hex): <void> — Updates the picker value using a hex string (e.g., "#FF0000") and updates all associated properties.
  • :SetRGBValue(<color3> color): <void> — Updates the picker value using a Color3.fromRGB() object and synchronizes UI state.
LUAU 
local colorpicker = my_own_section:AddColorpicker("colorpicker", Color3.fromRGB(255, 255, 255), function(color3rgb)
    print(color3rgb)
end)

colorpicker:SetHexValue("#FF0000")
colorpicker:SetRGBValue(Color3.fromRGB(0, 255, 0))

Dropdown / AddDropdown

section:AddDropdown(<string> feature_name, <array> default_list, <closure> callback): <table>

Provides a single-choice expandable selection list populated with custom string items. Fires callback(selected_item: string) on choice.

  • :Select(<string> text): <void> — Selects an existing item from the current list programmatically.
  • :ChangeItems(<array> list): <void> — Wipes old options and replaces them with the new array of string choices.
LUAU 
local dropdown = my_own_section:AddDropdown("dropdown", {"list #1", "list #2"}, function(selected)
    shared.Notify(selected, 2)
end)

dropdown:Select("list #2")
dropdown:ChangeItems({"changed 1", "changed 2"})

PlayerDropdown / AddPlayerDropdown

section:AddPlayerDropdown(<string> feature_name, <closure> callback): <void>

An automated player list dropdown that continuously synchronizes with players currently in the Roblox server. When an entry is chosen, it directly passes the target Player Instance (not merely a string) to the callback.

LUAU 
my_own_section:AddPlayerDropdown("make gay", function(player)
    shared.Notify(player.Name .. " is now a gay person.", 1)
end)

TextBox / AddTextBox

section:AddTextBox(<string> feature_name, <closure> callback): <void>

Provides a user text field for free-form string input. Fires callback(text: string) when the user commits/submits the text.

LUAU 
my_own_section:AddTextBox("textbox", function(text)
    shared.Notify(text)
end)

Button / AddButton

section:AddButton(<string> feature_name, <closure> callback): <void>

Creates a clickable trigger button. Fires callback() immediately upon click.

LUAU 
my_own_section:AddButton("button", function()
    shared.Notify("this is a button", 2)
end)

Keybind / AddKeybind

section:AddKeybind(<string> feature_name, <string> default_key, <closure> callback): <void>

Registers a rebindable keyboard shortcut. Fires callback() whenever the user presses the assigned key.

LUAU 
my_own_section:AddKeybind("keybind", "U", function()
    shared.Notify("Keybind test", 1)
end)

Notifications / Notify

shared.Notify(<string> text, <integer> type?): <void>

Pops up an integrated Overdrive H notification banner on screen. The integer type parameter controls banner styling and icon:

  • 0 — Warning
  • 1 — Error
  • 2 — Success
  • 3 — Information
LUAU 
shared.Notify("Addon loaded successfully!", 2)

Identifiers & User Metadata

shared.<field_name>: boolean | string

Provides real-time environment metadata, hardware verification, and user tier privilege booleans:

  • shared.is_premium_user — boolean: whether user has Premium tier.
  • shared.is_exclusive_user — boolean: whether user has Exclusive tier.
  • shared.is_serverbooster_user — boolean: whether user is boosting the server.
  • shared.discord_name — string: user's authenticated Discord username.
  • shared.discord_id — string: user's Discord snowflake ID.
  • shared.executor — string: client environment / executor identifier.
  • shared.hwid — string: unique hardware identifier hash.
LUAU 
print("Premium:", shared.is_premium_user)
print("Exclusive:", shared.is_exclusive_user)
print("ServerBooster:", shared.is_serverbooster_user)
print("Discord Name:", shared.discord_name)
print("Discord ID:", shared.discord_id)
print("Executor:", shared.executor)
print("HWID:", shared.hwid)
